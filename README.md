Select projects from [100 Days of Code: The Complete Professional Python Bootcamp](https://www.udemy.com/course/100-days-of-code/) by Angela Yu.

|----:|---------|--------------|
| 01 | [Band Name Generator](band-name-generator/) | `print()` · `input()` · variables · f-strings |

| 03 | [Downing Street Game](downing-street-game/) | `if`/`elif`/`else` · nested conditionals · multiline strings |
| 07 | [Hangman](hangman/) | capstone of days 4-6: randomisation · lists · `while` loops |
| 08 | [Caesar Cipher](caesar-cipher/) | defining functions · keyword arguments · modulo `%` |
| 11 | [Blackjack](blackjack/) | list methods (`pop`/`append`) · `global` state · `random` |
| 12 | [Number Guessing Game](number-guessing-game/) | scope (global vs local) · constants · return values |
| 15 | [Coffee Machine](coffee-machine/) | nested dictionaries · docstrings · `round()` |
| 16 | [Turtle Timmy](turtle-timmy/) | objects & methods · `import as` aliases · tuples (RGB) · turtle graphics |
| 16 | [Coffee Machine (OOP)](oop-coffee-machine/) | composing objects · imports across files · short-circuit `and` · OOP refactor of Day 15 |
| 17 | [Quiz Game](quiz-game/) | writing classes · `__init__` · attributes & methods |

| 28 | [Pomodoro](pomodoro/) | `tkinter` GUI · event-driven `window.after()` timers · canvas text over images |
| 31 | [Flash Card](flash-card/) | `tkinter` canvas images · `after()`/`after_cancel()` timers · `pandas` `to_dict(orient="records")` · saving progress to CSV |
